# AgroSankalp: Multi-Utility Web Application for Farmers

Welcome to the **AgroSankalp** repository! This project aims to bring together robust technological features to empower farmers worldwide, promoting sustainable and optimized agricultural practices.

## Overview
AgroSankalp is designed as a multi-utility companion allowing users to monitor their environment, market demand, and plan smarter. It leverages modern web technologies to present vital information cleanly and interactively.

## Features
- **Smart Weather Tracking:** Hyper-local forecasts to plan agricultural cycles without disruptions.
- **Market Price Quotes:** Live integrations to access national and local market prices.
- **Crop Support:** AI-driven tools focusing on pest controls, fertilizer recommendations, and farming guides.

## Technology Stack
- **Build Tool:** Vite
- **Core Library:** Vanilla HTML & JavaScript
- **Styling:** Vanilla CSS (Responsive, Modern UI with Glassmorphism & Dark Mode)

## Running Locally

To jumpstart the development environment:

1. Use `npm install` to download dependencies.
2. Run `npm run dev` to start the local server.
3. Your application will be available at `http://localhost:5173/`

## Project Architecture
The project files are structured as follows:
- `index.html`: Entry point and semantic structural core.
- `src/style.css`: Contains robust, variable-driven, dynamic aesthetic designs and utility configurations.
- `src/main.js`: Main JavaScript logic linking interactive elements like theme-toggling.
